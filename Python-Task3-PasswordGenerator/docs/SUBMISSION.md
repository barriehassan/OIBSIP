# Submission checklist

Use disposable demonstration values. Do not show real credentials.

- Confirm the assigned task number and current internship submission/AI-use rules.
- Install from a fresh checkout using the README.
- Launch `main.py` and check layout at your normal screen size.
- Generate at lengths 8, 18 and 64; inspect category inclusion and lookalike exclusion.
- Edit the numeric length; check that slider and numeric input agree.
- Try invalid lengths and fewer than two categories; confirm helpful errors.
- Show/hide output, copy it into a temporary local text editor, and delete the pasted value.
- Enable automatic copy, generate, verify the clipboard, then disable it.
- Generate six values; confirm only the latest five remain in history.
- Reveal/hide history, copy an old item, clear history, and restart to check that it is empty.
- Run tests and record the actual OS/Python versions and results.
- Record a brief demonstration explaining validation, `secrets`, rejection sampling, and module boundaries.
- Add your own screenshots/video links only after capturing and reviewing them.
